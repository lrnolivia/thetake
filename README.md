# The Take

Private, browser-only CHOP Barbershop pay calculator and projection tool.

## Local development

```sh
npm install
npm run dev
```

The production build is generated with `npm run build`. It includes self-hosted OCR runtime assets and can be deployed as Cloudflare Worker Static Assets.

Before connecting or deploying the repository, follow [CLOUDFLARE_SETUP.md](./CLOUDFLARE_SETUP.md).
